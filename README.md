# 첫 잔 앞에서 — 술의 배신 코치 (PWA)

술자리 유혹 앞에서 바로 꺼내 보는 금주 코치 웹앱입니다. 책 《술의 배신》의 관점을 상황별로 요약했고, 설치 후에는 오프라인에서도 열립니다. 서버나 빌드 과정 없이 정적 파일만으로 동작합니다.

## 파일 구성

| 파일 | 역할 |
| --- | --- |
| `index.html` | 앱 전체 (화면, 스타일, 내용, 동작) |
| `manifest.webmanifest` | 홈 화면 설치 정보 (이름, 아이콘, 색상) |
| `sw.js` | 서비스 워커 (오프라인 캐시) |
| `icons/` | 앱 아이콘 (192, 512, 마스커블, 애플 터치) |
| `.github/workflows/pages.yml` | GitHub Pages 자동 배포 |

## GitHub Pages로 배포하기

1. 새 저장소를 만들고 이 파일들을 그대로 올립니다 (`index.html`이 저장소 최상위에 있어야 합니다).
2. 저장소 **Settings → Pages → Source**를 **GitHub Actions**로 선택합니다.
3. `main` 브랜치에 push하면 자동 배포됩니다. 주소는 `https://<아이디>.github.io/<저장소명>/` 입니다.
4. 휴대폰 브라우저로 그 주소를 열고 **홈 화면에 추가**(iOS는 Safari 공유 버튼, 안드로이드는 Chrome 메뉴의 앱 설치)를 누릅니다.

Actions 대신 브랜치에서 바로 배포하려면 Source를 "Deploy from a branch"로 선택하고 `main` / `/ (root)`를 고르면 됩니다. 이 경우 `.github` 폴더는 지워도 됩니다.

## 내용 수정하기

- 상황별 내용: `index.html` 안의 `const S=[ ... ]` 배열 (각 항목의 `book`, `mind`, `say`, `do`)
- 믿음 깨기: `const M=[ ... ]`
- 핵심 원칙: `const P=[ ... ]`
- 술자리 전 점검 항목: `const CK=[ ... ]`

## 수정 후 꼭 할 일

`sw.js` 맨 위의 `CACHE = "sober-coach-v1"` 숫자를 올리세요 (`v2`, `v3` ...). 올리지 않으면 이미 설치한 기기에 옛 내용이 계속 보일 수 있습니다. 파일을 추가했다면 `sw.js`의 `FILES` 목록에도 넣어야 합니다.

## 로컬에서 확인하기

서비스 워커는 `file://`에서는 동작하지 않습니다. 폴더에서 아래처럼 실행하세요.

```bash
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000
```

## 개인정보

결단문과 점검 체크 상태는 브라우저 `localStorage`에만 저장되며 어디로도 전송되지 않습니다. 브라우저 데이터를 지우면 함께 지워집니다.
